# Кандидат выпуска: согласия, доступ и паспорт

## Состав

- Реквизиты оператора, фиксируемые тексты согласий и проверка snapshot.
- Подтверждение допуска к рабочим ролям, сохранение scope, отзыв доступа.
- Подтверждённый организатор для регистрации и запуска турнира.
- Защита фото, приватный просмотр и предотвращение обхода через вложения.
- UUID аудита паспорта, включая существующую запись при повторном upsert.
- Перенесён кодовый фикс ISF ID из `1cc6a66`: `expires_in` соответствует сроку
  assertion, а не сроку authorization code. Старые nginx-файлы не переносились.

Это выпуск текущего среза, а не завершение всего backlog: платежи, offline,
retention, анонимизация и организационные решения остаются отдельными задачами.

## Проверенное состояние инфраструктуры

Проверено 2026-09-19 через Vercel CLI/API и HTTP, без вывода значений секретов:

- `streetlifting-api`: последние production/preview deployment в состоянии Error.
  Production build остановился на отсутствии `DATABASE_URL`.
- `streetlifting-isf-id`: последние production/preview deployment в состоянии Error.
- `streetlifting-web`: production deployment Ready; само это состояние не доказывает
  готовность backend или переключение домена.
- У проектов API/ISF ID нет переменных подключения к БД; у API нет Blob token.
  У ISF ID отсутствуют signing/session/challenge/authorization-code secrets и SMTP
  credentials. Не подменять эти настройки фиктивными production-значениями.
- `streetlifting.app/api/health` и `api.streetlifting.app/health` возвращают 200
  с nginx старого контура; `id.streetlifting.app/health` возвращает 200 через
  Cloudflare. Это проверка доступности, а не авторизованный функциональный smoke.
- Node 20 в Vercel помечен deprecated; журнал предупреждает о прекращении новых
  сборок на этой версии с 2026-10-01. Перед переходом после этой даты нужен Node 24.

## Решение о данных и подготовка переключения

Владелец подтвердил сохранение и перенос существующих данных. На исходном сервере
созданы закрытые резервные копии обеих БД и настроек. Контрольные количества:
15 пользователей, 3716 спортсменов, 461 соревнование, 10 аккаунтов ISF ID,
0 файловых вложений. История миграций переносится целиком, включая отсутствующие
в этой ветке исторические миграции.

Созданы отдельные проекты Neon `streetlifting-api-vercel` и
`streetlifting-isf-id-vercel`, приватное Blob-хранилище `streetlifting-uploads`.
Настройки API/ISF ID перенесены без публикации секретов; Node Vercel обновлён до 24.
`VITE_LIVE_UPDATES_WS=false` отключает попытки WebSocket на serverless frontend,
существующий HTTP polling остаётся активным.

Все 8 desktop/mobile браузерных проверок и fresh/upgrade DB checks прошли:
`output/personal-data-db/run-9BaG9B/result.json`. Общий `pnpm release:check` прошёл;
после исправления polling повторно проверены lint и web typecheck.

DNS обслуживает Cloudflare; в доступном аккаунте зона отсутствует. До получения
доступа возможен переход через существующий nginx с проксированием в Vercel.
Факт production-переключения и финальная сверка данных фиксируются отдельно.

Миграция допуска проверена на синтетических fresh/upgrade БД. Она не принимает
обязательство за старых пользователей. API/web выпускаются согласованно.
Нельзя объявлять этот релиз production-ready по одним локальным тестам.
